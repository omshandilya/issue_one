# Ticket T7: One-click start, no installation

## Brief Summary
- **Issue Name:** One-click start, no installation
- **Issue Explanation (Brief):** Field teams use standard government Windows laptops without administrative rights, internet connectivity, or pre-installed developer tools (Python, Node, npm, pip). Running the portal previously required manual installation of dependencies and running 4 separate commands across 4 terminal windows.
- **Solution Explanation (Brief):** Created a zero-installation portable distribution in `package/Orbit Portal/` (~167 MB, well below the 300 MB limit) containing a self-contained portable Python runtime, pre-built static web assets (served directly via FastAPI so Node is not needed), pre-seeded SQLite database with demo scenes, a Windows Job Object-backed launcher (`launch.py`) for dynamic port allocation and guaranteed clean termination on window close, and a single double-clickable `start.bat`.

---

## What Was Needed
1. A single folder distributable on a USB stick or desktop.
2. Runs on clean Windows 10/11 machines without admin privileges, Python, Node, or internet.
3. Single double-click (`start.bat`) starts all services (catalog, tiles, gateway) and opens the default browser to the web portal.
4. Includes demo scenes so searching, scene browsing, and downloads work immediately offline.
5. Operates in folders with spaces (e.g. `C:\Users\Priya Nair\Desktop\Orbit Portal\`).
6. Conflict-free startup: dynamically selects available ports if default ports (8000, 8001, 8002) are occupied.
7. Clean shutdown: closing the console window or pressing Ctrl+C stops all processes with zero leftover background processes.
8. Clear `README.txt` for field staff.
9. Package build script in `packaging/build_package.py` and package under 300 MB.

## How the Package Was Produced
1. **Build Script:** Authored `packaging/build_package.py`.
2. **Frontend Compilation:** Executed `npm run build` in `web/` to compile Vite/React TypeScript into static HTML/CSS/JS bundles under `web/dist/`. By mounting `web/dist` directly in the FastAPI gateway application via `StaticFiles`, Node.js is completely eliminated from runtime requirements.
3. **Portable Python Assembly:**
   - Bundled the standalone Python binaries (`python.exe`, `pythonw.exe`, `python315.dll`, `vcruntime140.dll`, etc.) and `DLLs/` into `package/Orbit Portal/python/`.
   - Copied the Python standard library `Lib/` (omitting non-essential directories like tests, idlelib, tkinter, and cache files).
   - Copied runtime dependencies (`fastapi`, `uvicorn`, `httpx`, `numpy`, `pillow`, `pydantic`, `starlette`) from `.venv/Lib/site-packages/` into `package/Orbit Portal/python/Lib/site-packages/`.
4. **Offline Demo Data:** Copied pre-seeded SQLite database `catalog.db` and demo imagery files into `package/Orbit Portal/data/`.
5. **Entrypoint Script (`start.bat`):**
   - Uses `cd /d "%~dp0"` to guarantee correct directory resolution when run from paths containing spaces or USB drive letters.
   - Invokes `python\python.exe launch.py`.
6. **Process Lifecycle & Dynamic Ports (`launch.py`):**
   - Probes port availability using loopback socket binding (`find_free_port()`). If port 8000/8001/8002 is busy, dynamically assigns available alternative ports.
   - Injects port settings into environment variables (`ORBIT_GATEWAY_PORT`, etc.) which `orbit/config.py` and the frontend respect.
   - Assigns the launcher process and all spawned child processes to a Windows **Job Object** configured with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`. When the console window is closed (or terminates for any reason), the Windows kernel forcibly terminates all subprocesses instantly, completely preventing orphan background processes.
   - Monitors Gateway health check until ready, then invokes `webbrowser.open()` to launch the browser.
7. **Documentation:** Provided clear, field-ready instructions in `package/Orbit Portal/README.txt`.

## How We Know It Works
1. **Package Footprint:**
   - Total package size is **166.9 MB**, well below the 300 MB requirement.
2. **Runtime Verification:**
   - Executed `package/Orbit Portal/python/python.exe` directly on the packaged files without environment activation; confirmed all backend dependencies (`orbit`, `fastapi`, `uvicorn`, `httpx`, `numpy`, `PIL`) import and run cleanly.
   - Tested port probing logic: confirmed alternative ports are automatically selected when 8000 is occupied.
   - Tested path robustness with paths containing spaces.
   - Tested Windows Job Object creation and process group binding.
