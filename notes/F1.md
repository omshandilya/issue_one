# Feature F1: Search by drawing any shape, and export the results

## Brief Summary
- **Issue Name:** Search by drawing any shape, and export the results
- **Issue Explanation (Brief):** Users needed the capability to query satellite scenes using arbitrary freeform polygons (including shapes with holes or shapes crossing the antimeridian) rather than bounding boxes, and to export matching results in streaming GeoJSON or CSV format without exhausting server memory.
- **Solution Explanation (Brief):** Implemented `validate_polygon()` and exact spatial overlap algorithms (point-in-polygon ray casting, edge-edge intersection, rect-in-polygon, hole exclusion, and antimeridian unwrapping) in `orbit/catalog/spatial.py`. Added `POST /search/polygon` and streaming `GET /export/{search_id}?format=geojson|csv` in `orbit/catalog/app.py` and routed them via `orbit/gateway/app.py`. Added polygon drawing tool (`web/src/map/drawPolygon.ts`) and GeoJSON/CSV export download buttons in `web/src/App.tsx`.

---

## What Was Needed
1. A tool on the map allowing analysts to click points and double-click to draw any search polygon.
2. An API route `POST /search/polygon` accepting GeoJSON `Polygon` geometry with an outer ring and optional holes.
3. Accurate overlap matching:
   - Scenes whose footprints overlap or touch the polygon are returned.
   - Scenes entirely inside a hole are excluded.
   - Scenes only overlapping the envelope/bounding box around the polygon are excluded.
   - Polygons crossing the date line ($180^\circ / -180^\circ$) near Fiji work seamlessly.
4. Input validation returning `400` with clear details on invalid geometry (non-polygon type, fewer than 3 distinct vertices, unclosed rings, self-intersecting edges).
5. Streaming export route `GET /export/{search_id}?format=geojson|csv`:
   - Streams results in chunks without building huge collections in memory (supporting 10,000+ scenes).
   - Generates compliant GeoJSON or properly escaped RFC 4180 CSV with UTC timestamps ending in `Z`.
   - Enforces user ownership (foreign users get 404).

## Implementation Details
1. **Geometry & Spatial Logic (`orbit/catalog/spatial.py`):**
   - `validate_polygon(geom)`: Checks type, ring closures, minimum vertex count, and performs self-intersection tests across non-adjacent segments.
   - `unwrap_ring()`: Unwraps longitudes continuously across the date line so antimeridian shapes form unified geometries.
   - `bbox_query_intervals()`: Decomposes unwrapped bounding envelopes into $[-180, 180]$ chunks and queries SQLite's `scene_rtree` index.
   - `rect_overlaps_polygon()`: Checks candidate scenes by testing vertex containment, edge-edge intersections, and exclusion if completely covered by any inner hole ring.
2. **Catalog API (`orbit/catalog/app.py` & `db.py`):**
   - Added `polygon_searches` table in SQLite schema to persist search metadata and matched scene IDs with user attribution.
   - `POST /search/polygon`: Executes polygon lookup, persists `search_id`, and returns paginated matching features.
   - `GET /export/{search_id}`: Validates `format` and user ownership. Streams chunked database batches using FastAPI's `StreamingResponse`.
3. **Gateway Forwarding (`orbit/gateway/app.py`):**
   - Added transparent forwarding for `POST /search/polygon` and streaming forwarding for `GET /export/{search_id}` with CORS and content-disposition headers.
4. **Web Frontend (`web/src/map/drawPolygon.ts` & `web/src/App.tsx`):**
   - Added polygon drawing interaction (click to plot vertices, live dashed preview, double-click to complete).
   - Added "Export GeoJSON" and "Export CSV" buttons to trigger authenticated file downloads.

## How We Know It Works
1. **Automated Test Suite:** Added `tests/test_f1.py` with 5 test scenarios:
   - `test_f1_polygon_search_basic`: Confirms polygon search finds overlapping scenes and returns valid search_id and features.
   - `test_f1_polygon_validation_errors`: Validates 400 responses for invalid types, unclosed rings, fewer than 3 distinct points, and self-intersecting figure-8 edges.
   - `test_f1_polygon_with_hole`: Verifies that scenes located entirely within a polygon's hole are excluded.
   - `test_f1_polygon_across_dateline_fiji`: Confirms polygon search crossing the 180° antimeridian correctly retrieves all 12 scenes.
   - `test_f1_export_geojson_and_csv_streaming`: Verifies streaming output format, CSV headers, RFC 4180 escaping, GeoJSON structure, user ownership protection (404 for different users), and format validation.
2. **Build Verification:**
